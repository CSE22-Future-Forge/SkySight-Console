# SAR Rescue (Android)

The rescue teams' phone app for the SAR Manifest (see [docs/ARCHITECTURE.md §9](../docs/ARCHITECTURE.md)).
It pairs with the ground-station laptop over the SAR-NET Wi-Fi and raises a siren with a full-screen
alert when the base reports a new victim. Teams accept, navigate with the offline map, and report the
rescue. Everything keeps working out of Wi-Fi range: actions and GPS fixes are queued and sent when
the phone is back in range.

React Native 0.86 with Expo SDK 57, using local builds only. No Expo or Google cloud services are
used at runtime.

## Toolchain (once)

```bash
bash tools/install_toolchain.sh   # JDK 17 + Android SDK into %USERPROFILE%\.sar-toolchain (no admin)
npm install --legacy-peer-deps
```

## Build

```bash
bash tools/build_android.sh           # debug APK (dev client): run `npm start` for the JS bundle
bash tools/build_android.sh release   # standalone APK with the JS bundled
```

The output is `android/app/build/outputs/apk/<variant>/app-<variant>.apk`. Install it with
`adb install -r <apk>`.

The `android/` folder is generated by `expo prebuild` and is not committed. All native settings live
in `app.json`, in `plugins/`, and in the local module `modules/sar-native`.

## Test

```bash
npm test            # jest: outbox order/idempotency/409 rollback, event application, WS replay/ack, geo
npm run typecheck
```

## How it is put together

| Piece | Where |
| --- | --- |
| Screens (pairing, map, full-screen alert, victim, rescue report, my jobs) | `src/app/` |
| WebSocket link: replay from `last_seq`, ack, ping/pong, reconnect, revoke | `src/core/ws.ts` |
| Outbox: optimistic actions sent in order, 409 rollback | `src/engine/outbox.ts` |
| Applying server events, deciding alarms and cancellations | `src/engine/events.ts` |
| Background engine: alarms + repeats, receipts, GPS buffer, sync tick | `src/engine/engine.ts` |
| Pairing: Wi-Fi, `/pair`, team choice, map download + SHA-256, link test | `src/engine/pairing.ts` |
| Native (Kotlin): Wi-Fi binding, foreground service, siren alarms, resumable download | `modules/sar-native/` |
| Offline map glyphs bundled into the APK | `assets/glyphs`, `plugins/withMapGlyphs.js` |

## Field checklist

- During pairing, allow location, notifications, full-screen alerts and "ignore battery optimisation".
  Without the battery exemption, Android can cut the connection while the screen is off.
- Pairing needs the laptop's `srilanka.pmtiles` (the download resumes if interrupted). After that,
  the map, GPS and actions all work in airplane mode with GPS on.
