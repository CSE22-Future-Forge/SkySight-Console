# SkySight Console

Human search & rescue console for UAV platforms using visible (RGB) and
long-wave infrared (thermal) payloads. It pairs with the **SAR Manifest ground
station**, a laptop coordinator console that alerts the rescue phones over a
local Wi-Fi network (no internet at runtime).

Two apps in this repo:

| App | Entry point | Launcher |
|---|---|---|
| SkySight Console (detection) | `main.py` | `run.bat` |
| SAR Manifest ground station | `ground_station/app.py` | `run_ground_station.bat` (or `ground_station\run.bat`) |

## Requirements

- Windows 10/11
- Python 3.11+ (developed on 3.14)
- Optional NVIDIA GPU (CUDA) for the fastest detector; CPU and Intel iGPU run
  the bundled OpenVINO INT8 models.

## Setup

Create the virtual environment once, from the repo root:

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install -r ground_station\requirements.txt
```

`torch`/`torchvision` are installed separately because the default PyPI wheels
are CPU-only. For the CUDA build, install them first, then the requirements:

```powershell
.venv\Scripts\python -m pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -r requirements.txt
```

### Models

The detector weights are committed, so a fresh clone runs without downloading
anything:

- `model/qs_yolov8s_person.pt`, `model/yolo26n.pt`, `model/yolo11n.pt` — RGB models.
- `model/openvino/` — prebuilt OpenVINO IR models (`qs_person_int8`,
  `yolo26n_e2e`) used by the **CPU / Intel iGPU** compute options.
- `fusion_model/weights/` — the RGB + thermal fusion network weights.

`fusion_model/export/` (ONNX + IR) is generated by
`python -m fusion_model.export_openvino` and is **not** needed to run the app.

## Run

```powershell
run.bat                         # SkySight Console GUI
run_ground_station.bat          # SAR Manifest ground station GUI
run_ground_station.bat --headless --seed-demo --pair   # server only + demo + pairing code
```

In the SkySight console, pick the model from the **Model** dropdown and the
execution backend from the **Compute** dropdown:

- **NVIDIA GPU** — torch/CUDA.
- **CPU (OpenVINO INT8)** / **Intel iGPU (OpenVINO INT8)** — the exported
  OpenVINO IR models in `model/openvino/`.

Ground-station runtime data lives in `%LOCALAPPDATA%\SARManifest`
(`manifest.db`, `images\`, `maps\`, `logs\`, `archives\`).

## Tests

```powershell
.venv\Scripts\python selftest.py            # headless core checks
.venv\Scripts\python -m pytest ground_station\tests -q
```

See `ground_station/README.md` for the first-mission walkthrough (map, teams,
pairing, detections) and `docs/ARCHITECTURE.md` for the full specification.

## Not committed

- `.venv/`, `__pycache__/`, `data/`, `*_db/`, `*.log` and sample videos are
  ignored.
- `kernel.errors.txt` (OpenVINO kernel error dump) and generated/experimental
  export output are scratch files and should not be committed.
